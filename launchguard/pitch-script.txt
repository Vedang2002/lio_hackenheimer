JURY QUESTIONS
Why not a spreadsheet? The tool computes timing-aware material constraints and creates persistent source-linked action drafts; the optional model extracts multilingual evidence. The UI alone is not the agent.
What happens when AI is wrong? Exact-quote checks, visible source/uncertainty and human review before normalization; deterministic tools never execute instructions embedded in documents.
Are you production ready? No. Live portal ingestion, verified supplier transport, richer capacity/numbering constraints and customer validation remain.
Can it run without Wi-Fi? The supplied sample and deterministic engine run locally. Local AI also requires a previously installed model.

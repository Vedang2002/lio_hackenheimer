Let the inbox do its work.

A Google Apps Script worker reads new customer messages and sends approved replies every minute, including when this page and your computer are closed.

Setup required. LaunchGuard has not connected your Gmail account, installed a timer or sent any messages. This worker runs in your Google account; mailbox activity is not displayed in this dashboard.

Connect and test

  1. Open Google Apps Script using the support account. Create a project and copy the code, configuration and manifest.
  2. Add the Gmail API service in the editor. Review the configured sender and reply text. Use draft mode for a first test.
  3. Run verifyGmailConnection and complete Google's consent flow yourself.
  4. Run startEmailAutomation. Send a new test email from another address, then check Gmail Drafts and run showEmailAutomationStatus.
  5. When ready to send, stop the worker, choose acknowledge or approved_rules, run acceptEmailConfiguration, then start again.

Automatic acknowledgments confirm receipt only. Approved-rule mode holds questions without one clear matching answer. Duplicate protection, loop filters and daily limits are included. Free-form AI sending is not enabled.

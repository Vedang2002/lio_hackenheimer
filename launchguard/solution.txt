4. AGENTS AND TOOLS

Evidence reader: local model reads original multilingual document text and returns English claims, original quotes and uncertainty. Verbatim-quote checking rejects unsupported output. Source documents are data and cannot override system instructions. Inventory is not changed by free-form model output.

Reconciliation tool: canonical component and lot IDs; ERP versus physical count; release holds; stale/future-dated evidence; no double counting goods already received. Conflicts remain visible instead of silently picking a convenient claim.

Feasibility tool: simulate only within shift windows and after usable arrival. Allocate shared parts by explicit customer-approved priority. Report projected finished copies and shortfalls per edition. The model does not do arithmetic. This is a fixed-priority simulation, not an optimization solver.

Action planner: writes source-linked requests for confirmation and evidence, and owner-assigned shortfall escalations. Actions persist with stable IDs and are deduplicated on rerun. A changed claim creates a fresh request. A human can review or dismiss. Drafts are not messages sent, purchase orders placed, or problems resolved.

The implementation supports these tools with local state and audit records. The AI reader is optional and unverified until a local model is configured; without it this is a deterministic planning prototype and does not yet satisfy the jury's AI demonstration requirement.

5. DECISIONS AND RECOVERY

Prioritize customer objectives using actual shortage cost per edition, contractual commitments and numbering constraints. Collector has all copies preordered, but that alone does not grant permission to divert shared parts from Standard. Confirm allocation with Maren.

For a missing component, calculate latest usable arrival by counting backward through working windows from dispatch using required remaining production time. Include receiving, QA, setup and loading buffer explicitly. Consider only existing, evidenced recovery options: earlier dispatch, partial release, verified inventory rework or approved substitutions. New orders probably arrive too late; no second packing site exists.

Commercial comparison:
Net expected benefit = incremental copies saved * customer-confirmed loss avoided per copy * recovery success probability - incremental freight/rework/overtime costs.
Show whether the input is a quote, measured fact or assumption. Ask the authorized owner to approve an exact option and amount. No legal release, price, approval limit, penalty or supplier obligation can be inferred without the actual policies and contract.
